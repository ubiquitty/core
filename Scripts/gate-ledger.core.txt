# What the gates of ubiquitty-core are held to.
#
# canary <gate>      a gate whose self-test a stanza of the driver already
#                    depends on; a scan that stops finding one is broken, and
#                    not a shrinking tree.
# budget <name> <n>  a count that must equal the tree's. It falls when the tree
#                    improves and never rises. A checkout holding several
#                    repositories sums their ledgers, since every count is over
#                    files and each file has one owner.
# tool <gate> <why>  a gate nothing invokes because a person runs it, and what
#                    invokes it instead.
# raised <name> <from> <to> <why>
#                    a budget that rose past the merge base's number, and why;
#                    Scripts/check-ledger-ratchet.py fails a rise without one.

tool check-daemon-replacement.py needs the opt-in acceptance binary and replaces private daemons, so it is run by hand as Tests/README.md describes
tool check-sync-transport.py needs the opt-in acceptance binary and a disposable fixture account or container, so it is run by hand as Tests/README.md describes
tool check-merge-ready.sh run by hand before a merge; there is no push at which it belongs
tool check-mutants.sh rebuilds and reruns per mutant, which is minutes a push cannot carry
