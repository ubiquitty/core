# The calls a frontend makes at a display tick, or after each frame it draws,
# that are not UBIQUITTY_NONBLOCKING, and why each still is not.
#
# A per-tick call is one the display-free cadence test's frontend thread makes
# (Tests/Core/Runtime/test_frame_cadence.cpp, `m_session.<member>(`). Every one
# is either declared UBIQUITTY_NONBLOCKING in TerminalSession.h, which Clang's
# -Wfunction-effects proves takes no lock and waits on nothing, or listed here
# with what it still does:
#
# - `waits`: it can wait for the model lock. Scripts/check-model-lock-holds.py
#   counts these into the ledger's `per-tick-waits` budget, which only falls:
#   a call leaves this list by losing its wait and gaining the mark.
# - `nowait`: it never waits, but calls what the function-effect analysis
#   cannot prove: a try-lock, or a read inside a hold its caller took.
#
# <member> <waits|nowait> <reason>
frameClockFactsNow nowait reads the writer's publication, its own or an adopted pane's, behind a thread assertion and the fake-tick environment
liveReadDecline nowait reads the model inside the live read's hold
lockForRead waits the live read waits for the model lock
nextAnimationDelay nowait reads the writer's publication, its own or an adopted pane's, behind a thread assertion and the fake-tick environment
presentationHoldTicksRemaining nowait reads the writer's publication, its own or an adopted pane's, and the monotonic clock
sendKey waits encodes the key and notes the activity under the model lock where no ingest loop drains the pane's own model (adopted, remote, fed)
setPresentedViewOffset nowait stores the offset; a remote link keeps the newest in a register and posts one session turn, which asks its host for history
setSyncFrameCaptureGeometry nowait publishes the registration, which whoever next holds the model lock folds in
shouldWithholdCapture nowait reads the model inside the live read's hold
shouldWithholdFrame waits judges an open synchronized update under the model lock where no ingest loop drains the pane's own model (a remote replica, a fed pane); a loop's owner stamps and expires it at its turn
takeEventFlags nowait polls the pane link's publication through its virtual interface
takeFrame waits judges an open synchronized update under the model lock where no ingest loop drains the pane's own model (a remote replica, a fed pane); a loop's owner stamps and expires it at its turn
terminal nowait hands the live read the model its hold covers
unlockForRead nowait releases the live read's hold
updateSelectionAfterOutput nowait try-locks the model to judge the selection after output, and never waits for it
